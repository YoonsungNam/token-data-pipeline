# mart/token-usage (Plan 3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** mart 일배치 모듈 구현 — STEP 0(커버리지 게이트)/STEP 1(fact×dim 조인·집계 4테이블)/STEP 2(view 적재) + 검증 + E2E + 배포 계층.

**Architecture:** `batch.py`(I/O 오케스트레이션) + `mart.py`(순수 로직) 분리(동료 s2job 관례). 변환은 전부 서버사이드 `INSERT INTO ... SELECT`(GLOBAL LEFT JOIN 표준, 파라미터 바인딩). 멱등성 = 존재 확인 → ALTER DELETE(local, ON CLUSTER) → wait_for_mutations(clusterAllReplicas 폴링) → INSERT(_dist 경유) → count 검증(재시도 10×5s).

**Tech Stack:** Python 3.10+(clickhouse-connect), bash, kustomize, GitHub Actions. 단위 테스트는 Fake client 주입(collectors와 동일 스타일).

## Global Constraints

- **Python 3.10 호환** (dev 3.10): StrEnum·tomllib 금지. 이미지/CI 3.12.
- **로컬에 docker 없음** (CI가 컨테이너 검증), **공유 클러스터 kubectl 변형 금지** (실 클러스터 검증은 Plan 5).
- **DB 상수 격리**: `DB_FACT="fact"`, `DB_DIM="gpu_data"`, `DB_MART="mart"` — mart DB 공유/전용은 §9-18 잔여 협의(PR #6) 중이므로 코드에서는 상수 3개로만 참조(주석: "§9-18 협의 변경 지점"). 테이블명 하드코딩 금지, `f"{DB_MART}.token_usage_1d_dist"` 형식.
- **계약 수치(§7.1/§7.2 — 임의 변경 금지)**: 스케줄 매일 **04:00 KST**(수집 02:00 + 데드라인 03:30 이후 — §5.9-9), `activeDeadlineSeconds: 1800`, resources requests 256Mi/limits 1Gi, wait_for_mutations 폴링 3s/타임아웃 300s, count 검증 재시도 10회/5초(RETRY_* env 조정 가능), org 매핑 실패율 경고 임계 기본 20%, module 마커 `module=mart-token`.
- **멱등 시퀀스(§7.1)**: 테이블별 존재 확인 SELECT(없으면 DELETE 스킵 — §4.0 뮤테이션 절감) → `ALTER TABLE <local> [ON CLUSTER] DELETE WHERE date={d} [AND created_by='token-pipeline' — view만]` → wait_for_mutations(`CH_CLUSTER` 설정 시 `clusterAllReplicas(cluster, system.mutations)`) → INSERT → count 검증. **INSERT는 전부 `_dist` 경유**(co-location — DDL 리뷰 확정), `insert_distributed_sync=1`.
- **created_by**: 모든 INSERT SELECT가 `'token-pipeline'`을 명시 삽입 (DEFAULT 없음 + CHECK — §4.2).
- **날짜·CLI 계약(§7.1=§5.1)**: `batch_time` ISO8601 위치 인자(기본 now, naive는 KST 해석), target_date = batch_time − 1일. `--from/--to`(inclusive, 쌍) 날짜범위 rerun — **날짜별로 STEP 0→2 전체를 독립 반복**. exit: 0 성공/1 FAILURE/2 인자 오류. aware datetime만 insert(수집기 C2 교훈 — naive 금지).
- **summary 부재/파생 시맨틱(§4.1/§4.3 v1.9)**: summary 행 없는 서비스 → reported_\*·diff_\* NULL. `is_derived=1` → diff_\* NULL (reported_\*는 값 유지). 거짓 "보고값 0" 금지.
- **미매핑 조직(§6.1)**: dim_user_org 미매핑 user_id → `org_path=['unknown']` (org_top='unknown', org_leaf='unknown').
- **마커(§5.6·§7.1)**: `BATCH_RESULT status=<S> module=mart-token coverage=N/M missing_services=<콤마목록|-> rows_mart=<n> rows_view=<n> warn=<n> elapsed=<s>` — **실행(날짜)당 1줄**, 날짜범위 rerun은 날짜별 1줄(§7.1 독립 반복 — collectors의 단일 집계 라인과 다른 계약임을 주석으로 명시). 로그에 user_id 원문·레코드 페이로드 금지.
- **dim 컬럼 인터페이스(Plan 4와의 계약 — 이 플랜이 정본을 정의)**: `gpu_data.dim_user_org(user_id String, effective_from Date, user_name String, org_path Array(String), org_depth UInt8, is_active UInt8, updated_at DateTime('Asia/Seoul'))`, `gpu_data.dim_model(model String, effective_from Date, provider LowCardinality(String), serving_type LowCardinality(String), input_usd_per_mtok Nullable(Float64), cache_read_usd_per_mtok Nullable(Float64), cache_creation_usd_per_mtok Nullable(Float64), output_usd_per_mtok Nullable(Float64), currency LowCardinality(String), note String)` — 단가 컬럼명은 여기서 확정(스펙 §4.2는 이름 미지정). **단가는 Nullable — `unknown` 시드 행은 전 단가 NULL**(§6.2 리뷰 #15: unknown 사용량의 cost는 산정 불가 NULL이지 $0가 아님 — cost 산식은 NULL 전파로 자연히 NULL). E2E 테스트 DDL이 이 스키마의 정본 초안이 되고 Plan 4가 상속.
- **재삽입 중복제거 차단**: 멱등 rerun(DELETE→동일 데이터 재INSERT)은 ReplicatedMergeTree **블록 중복제거에 걸려 조용히 폐기**될 수 있다 — 모든 INSERT SELECT에 `insert_deduplicate=0` 설정 필수(테스트로 계약 고정). Distributed 경유 전파가 환경에 따라 불완전한 사례가 있어 **서버측 보강으로 `ALTER USER token_mart SETTINGS insert_deduplicate = 0`을 accounts.sql에 포함**(PR #6 반영). Plan 5 stage 검증 항목: "동일 날짜 rerun 2회 후 행수 보존".
- **레플리카 지연 게이트(company 2s×2r)**: detail 적재 직후 agg가 _dist로 detail을 읽을 때 지연 레플리카 라우팅 시 무음 과소집계 가능 — `INSERT_QUORUM` env(기본 '' = 미적용, company는 install.sh가 `auto` 주입)로 insert_quorum을 조건 적용. CI 단일노드/stage 1r에서는 미설정(§9-19 연계 — company 반입 검증 항목).
- 사내 URL·비밀번호·실사용자 데이터 커밋 금지. 커밋 관례 `feat(mart): ...`, 태스크당 1커밋 이상.

    eff_org AS (

        WHERE effective_from <= {d:Date}
        GROUP BY user_id

        -- 단가는 Nullable — 미등록 모델(join miss)·unknown(전 단가 NULL 시드) 모두

               argMax(provider, effective_from)                 AS provider,

               argMax(cache_read_usd_per_mtok, effective_from)  AS p_cr,
               argMax(cache_creation_usd_per_mtok, effective_from) AS p_cc,
               argMax(output_usd_per_mtok, effective_from)      AS p_out
        FROM {DB_DIM}.dim_model_dist
        WHERE effective_from <= {d:Date}
        GROUP BY model

    r.service_group,
    r.service,
    r.user_id,

    r.model,
